2. Was die App ist

Content Machine ist ein privates Programm, das ausschließlich auf dem eigenen Computer des Betreibers läuft. Es lädt selbst produzierte Videos auf die eigenen Kanäle und Accounts des Betreibers hoch und liest deren Statistiken aus. Die App wird keinen anderen Personen angeboten.

3. Welche Daten verarbeitet werden

Nach der Anmeldung mit einem Google-Konto greift die App über die YouTube Data API und die YouTube Analytics API auf folgende Daten zu:

  • Grundinformationen zum verbundenen YouTube-Kanal (Name, Kanal-ID)
  • das Hochladen von Videos samt Titel, Beschreibung und Vorschaubild
  • Statistiken der hochgeladenen Videos (z. B. Aufrufe, Wiedergabedauer)

Für Instagram und TikTok gilt dasselbe: Die App postet Videos auf die verbundenen Accounts und liest deren Statistiken.

4. Speicherung

Zugangsschlüssel (Tokens) und Statistiken werden ausschließlich lokal auf dem Computer des Betreibers gespeichert. Es gibt keinen Server und keine Weitergabe an Dritte. Die Daten werden nicht verkauft und nicht für Werbung verwendet.

5. Google-API-Dienste

Die Nutzung von Informationen, die über Google-APIs empfangen werden, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use). Die App nutzt YouTube API Services; es gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google.

6. Zugriff widerrufen

Der Zugriff der App kann jederzeit unter myaccount.google.com/permissions widerrufen werden. Die lokal gespeicherten Daten werden dann gelöscht.
